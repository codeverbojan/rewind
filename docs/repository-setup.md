# Repository contents

Start with [Build and installation](getting-started.md).

The public repository contains current original native source, tests, pinned dependency/patch descriptions, selected authored diagnostic resources, documentation and a curated screenshot gallery. It was prepared as a clean public snapshot; the earlier private development history and raw evidence archive remain local.

Local-only inputs include `downloads/`, `diagnostics/`, frozen `versions/`, build outputs, `AGENTS.md` device handoffs, research responses, harvested catalog JSON, ratings databases, standalone commercial artwork, signing files and private device-control setup. Public source is not a substitute for the complete private research archive.

The native app source has not been changed to manufacture a complete clean-clone build. Historical build scripts still name omitted prerequisites; the setup guide makes those requirements explicit. The portable checks work without those prerequisites.
