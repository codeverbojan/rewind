# Security policy

This is experimental software, with no promise of production security support or updates for an end-of-life operating system.

For a vulnerability, use [Report a vulnerability](https://github.com/codeverbojan/rewind/security/advisories/new) instead of posting credentials or exploit details in a public issue. Include affected code/version, impact and a minimal reproduction with synthetic data. Never include Apple passwords, private keys, signing profiles, tracker passkeys or device pairing records.

Source URLs and metadata are untrusted input. Changes should preserve bounded requests, certificate verification where supported, source identity, cancellation, storage limits and separation between private trackers and public discovery.
