# Rewind native application

This directory contains the Objective-C/UIKit application, Objective-C++ playback and torrent adapters, and C++ policies. The current source checkpoint is iPad 0.300, with a separate ARM64 iPhone 0.301 build recipe.

- [Project overview and interface](../README.md)
- [Architecture](../docs/architecture.md)
- [Build requirements](../docs/getting-started.md)
- [Status and remaining verification](../docs/status.md)
- [Third-party notices](../THIRD_PARTY_NOTICES.md)

Historical device handoffs, harvested research data and frozen binary archives are local-only. This public source release does not include a signed application or a complete native build bootstrap. Run the portable checks from the repository root before preparing a separate native environment.
